## 3. 修掉的缺陷（实测值）

| # | 缺陷 | 修复前实测 | 修复后实测 |
| --- | --- | --- | --- |

| 3 | 字段标签对比度不足 | **3.09:1**（11px/800 的 TYPE / TAGS / AGENT / VERSION） | **4.73:1** |

## 4. 关键决策与理由

- **卡片标题用 heading 内的真 `<button>`，而不是给 `<article>` 加 `role="button"`**：`role="button"` 会把 heading 与描述从无障碍树里剪掉（button 的子节点是 presentational），而描述正是卡片的主体；「铺满整卡的 overlay button」则会盖住卡片自己的描述滚动区——那是用户明确要求保留的。heading 内放 button 是标准的可点击卡片模式：heading 语义保留、按钮进 Tab 序、滚动区照常可用。按钮需 `stopPropagation`，否则一次点击经冒泡会把弹窗开两次（已加测试）。
- **对比度按卡片渐变的最差一站断言**，不是按白色。这是最容易搞错的地方：`--hub-muted` 在白底上是 4.79:1（达标），只有算上类型色底才暴露 4.23:1。
- **空状态只在标签场景给动作**：类型筛选的「修复手段」就是屏幕上已有的类型 chip，再加按钮是冗余；标签选择没有别的出口。
- **分页间距抽成 `--hub-page-inset-end`**：页面底部内边距与被分页条覆盖的那段原本是两处独立字面量，抽成 token 后不可能再漂移。

## 5. 已知取舍与验证限制

- **卡片描述保留卡内滚动**（用户确认）：58%–71% 的描述默认不可见，且是嵌套滚动（鼠标滚轮在卡上先滚卡内 147px 才继续滚页面）。这是有意的设计，本轮不动。
- **headless 下无法用 Enter/Space 验证激活**：`document.hasFocus()` 为 false 时，浏览器不为**任何**按钮由按键合成 click——用既有按钮（tab 行的 scope 按钮）做了对照，同样不触发，故属环境限制而非卡片缺陷。因此：
  - **键盘可达性**在真实浏览器验证：34 次 Tab 之内精确落在 `.power-card__open` 上（第 18 个）；`:focus-visible` 匹配时 `outline` 为 `solid 3px rgb(101, 80, 216)`、`outline-offset: 2px`（不透明、可见）。
  - **激活行为**由 jsdom 测试覆盖（点击触发一次、不重复、`busy` 时禁用）。
- **`:focus-visible` 的可见性需要窗口有焦点才成立**：脚本用 `el.focus()` 时 `matches(':focus-visible')` 为 false；用真实 Tab 键序列（并在需要时先给页面一次指针交互）才匹配。这是 Firefox 的判定规则，不是样式问题。

## 6. 契约测试（本次核心）

这些缺陷的共同点是**静默**：值与结构都「有测试」，但「在真实渲染里是否可见/生效」从未被断言。每处修复都补在原来缺的那一层：

| 测试 | 断言 |
| --- | --- |
| `keeps the focus ring opaque so it is actually visible` | `--hub-focus` 必须是不含 alpha 的 `light-dark(#hex, #hex)`；`outline` 简写含 `solid`、线宽 ≥2；焦点规则必须覆盖可点击卡片 |
| `keeps every text token at or above its contrast floor` | 按 WCAG 公式算 `--hub-muted`（对**四个类型色底**逐一）与 `--hub-label`（对面板白）在明暗两套下均 ≥4.5 |
| `resets the card title button at a specificity that beats the base button rule` | 重置规则必须带 `.agent-hub`（(0,2,0) 压过基础按钮规则的 (0,1,1)）；禁止裸 `.power-card__open` 回归 |
| `seats the sticky pagination on the scrollport edge` | 分页 `bottom` 必须用 `--hub-page-inset-end` 贴边、padding 同步增长、背景不透明、仍为 sticky |
| `pins the pagination to the bottom of the page scroller`（改写） | 旧的 `bottom: 0` 断言按新口径更新 |
| `opens details from the keyboard, not only from a pointer` / `fires the details once per press` / `disables the keyboard control while a write is in flight` | 标题按钮存在且在 heading 内、一次按下只触发一次、`busy` 时禁用 |
| `names the tag filter …` / `offers to clear the tags …` / `names the type filter …` | 空状态按筛选分层、标签场景动作可恢复列表、类型场景不给多余动作 |
| `interpolates the type and agent into the empty-list copy` | 新增的带占位符文案在中文下正确替换 |

**反向验证（变异测试）**，均按预期失败：

| 变异 | 失败用例 |
| --- | --- |
| 焦点环改回 28% alpha | `keeps the focus ring opaque …` |
| 两个 token 改回旧值 | `keeps every text token …`（4.23 < 4.5） |
| 去掉标题按钮的 `.agent-hub` | `resets the card title button …` |
| 去掉标签专属空状态文案 | 2 条空状态用例 |
| 分页 `bottom` 改回 `0` | `seats the sticky pagination …` + `pins the pagination …` |
