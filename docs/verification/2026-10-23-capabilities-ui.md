# 能力中心 UI 源码交付与验收

## 交付位置

本轮修改位于正式 `bibit-agenthub-plugin` 仓库的 `src/`，分支为 `codex/capabilities-ui`，基于 `bianbu-26.04` 的 `0150dd3`。研发应同步该分支、构建签名插件并更新宿主加载的 bundle 或插件包。仅更新 `bibit-gui/demo-ui-v3` 不会替换独立插件。

本地浏览器预览与验收数据没有纳入提交。插件版本仍为 0.4.4，本次是源码审查交付，尚未发布或部署新版软件包。

## 修改与保留的交互

- 类型与标签改为搜索框左侧的下拉控件，标签保留多选交集语义；搜索覆盖完整目录，聚合系列后再分页。
- 卡片点击打开原详情；卡片隐藏版本号，详情保留版本选择、安装、更新、降级与卸载。
- 仅确认未安装的市场能力在 hover 或键盘聚焦时显示「添加能力」；触屏设备直接显示可用操作。安装前重新检查，已安装任意版本时不覆盖，提示进入详情管理。
- 已安装标签位于底部标签首项，使用宿主 `--primary` 与 `--primary-foreground`。底部共用 32px 最小高度，不带分割线。创建按钮最小宽度 96px。
- 保留 Custom、New、Agent 选择、全部更新、自定义资源上传/删除、警告与分页。正式页面不存在预览中的冗余介绍块和数量说明，因此保留原页面标题。
- 页面与控件优先读取宿主主题 token，复用插件现有组件与 service:store，不引入宿主私有组件或变更 Provider wire 协议。

浏览器验收使用仓库外临时入口，直接导入正式 AgentHubPage、i18n 和 CSS，仅以 Host API 内存 fixtures 替代业务数据。在 1280×720 下验证：

- 普通已安装、未安装与自定义卡片正常态均高 264px，底部均为 32px；创建按钮宽 96px。
- 安装标签为 `rgb(178, 228, 13)` 背景、黑色文字；深色主题卡片正确跟随宿主 token。
- 我的能力无添加按钮；市场未安装按钮默认隐藏，键盘聚焦后可达。
- 点击卡片描述打开原详情；点击添加不会打开详情，完成后出现已安装标签并移除添加按钮。
- 标签多选按交集过滤，重载期间菜单和复选框焦点保持；搜索可命中原第二页的能力。

安装时序、防重复提交、过期卡片防覆盖、未能读取清单时隐藏添加入口，以及原有更新/降级/卸载流程由自动化测试覆盖。本轮没有在开发板执行真实安装或发布。

本机 Node 的 zlib 为上游构建，与 CI/板端 zlib-ng 不同；本地插件包用于构建验证，不将其哈希作为发布哈希。研发发布时仍应使用项目既定 CI/板端工具链。
