# 插件中英文跟随 Bibit 系统语言

日期：2026-09-10
范围：`bibit-agenthub-plugin` 0.3.0（前端 contribution、领域消息、Manifest、Dev Host、文档与测试）
参考实现：`../bibit-runtime-plugin`（`src/runtime-i18n.tsx` 模式）

## 结论

插件把全部自有文案改为以英文为源语言、按宿主传入的 `language` 翻译成中文；菜单、导航与描述键通过 `pluginLocales` 交给宿主解析。语言切换只替换文案，不重挂载页面、不重启列表请求、不改变安装状态机。0.3.0 的构建产物与本地验证已通过；板端真实宿主下的语言切换尚未执行（见「未验证项」）。

## 宿主契约证据

| 证据 | 来源 | 结论 |
| --- | --- | --- |
| contribution 收到 `language` | 发布版 `~/Downloads/bi-bit_0.1.4_riscv64.deb` 内的 `FeatureContributionHost` 传参（`language: u.language ?? "en"`） | 0.1.4 起宿主会把语言传给页面与设置 contribution |
| 设置导航 `titleKey` | `../bibit` 提交 `b0bcc45 feat(feature-sdk): localize plugin settings navigation`（随 `bianbu/0.1.4` 发布） | 0.1.4 起设置子菜单标题可用 `navigation.titleKey` 解析 |
| 宿主支持语言集合 | 宿主 i18n `SUPPORTED_LANGUAGES = ["en","zh-CN"]`、`fallbackLng: "en"` | 插件只需提供 `en` 与 `zh-CN`；缺省语言为英文 |
| 菜单资源来源 | `trustedPluginLoader` 读取 bundle 导出的 `pluginLocales` 并 `registerFeatureLocales(featureId, locales)` | 必须从插件入口命名导出 `pluginLocales` |

## 实现要点

- `src/agentHubI18n.tsx`：`agentHubChinese`（英文源串 → 中文）、`agentHubLocales`（`en` / `zh-CN`）、`AgentHubI18nProvider`、身份稳定的 `useAgentHubI18n`、`withAgentHubI18n`；占位符用 `{version}` 形式的 `values` 插值；缺条目回落英文源串。
- 数据层不保存语言：`src/api/operationMessages.ts` 与 `src/api/installationStore.ts` 的文案改为 `TranslatableText { text, values? }`，在组件渲染边界翻译。
- Manifest：`contributions.locales` 为 `["en","zh-CN"]`；设置 contribution 增加 `navigation.titleKey` 与 `fallbackTitle`；版本 `0.3.0`。
- Dev Host：`dev/main.tsx` 增加语言下拉框与 `?lang=zh-CN` 初始值，并透传 `language`。
- 不重挂载：Provider 子树不加 `key`，列表 effect 依赖不含 `language`；此前 `3f75a2b` 的稳定 `service:store` 代理保持不变。

测试覆盖的重点回归：

- `src/agentHubI18n.test.tsx`：语言归一化（`zh` / `zh-CN` / 缺省 → 英文）、中英渲染、切换、回落、插值、菜单键对齐，以及「词典键必须仍是源码字面量」的死键检查；
- `src/AgentHubPage.test.tsx`：切换语言后页面各层文案改变、`powers.list.v1` 请求数不变、已打开的详情弹窗与已选版本保持；
- 各组件与 `src/AgentHubSettingsPage.test.tsx`：中英文两种渲染与保存/读取状态文案；
- `src/feature.test.ts`：Manifest 与 Feature Module 不变量、`pluginLocales` 导出、`agentHub:settings` 键在中英两套资源中可解析。

另外修掉了 `2026-09-09` 记录过的 `PowerFilters > opens the Agent menu with ArrowDown and restores focus with Escape` 时序失败：触发键的 `ArrowDown` 会额外在一个 `requestAnimationFrame` 里聚焦首项，该帧若落在后续按键与断言之间会改变环绕索引。测试现在先等待该帧落定并逐步 `waitFor`，不再依赖调度顺序（组件行为未改动）。
